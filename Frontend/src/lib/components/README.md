# Shared Components

Reusable Svelte 5 components provide the CargoSettle visual language and role navigation.

- [AppShell.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/AppShell.svelte) contains responsive role navigation, search, notifications, and page framing.
- [Icon.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/Icon.svelte) contains the local inline SVG icon set.
- [MetricCard.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/MetricCard.svelte) renders repeated dashboard KPI cards.
- [StatusBadge.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/StatusBadge.svelte) renders semantic status labels.
- [DemoModal.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/DemoModal.svelte) provides local form, preview, confirmation, and action dialogs.
- [WalletButton.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/WalletButton.svelte) connects MetaMask, verifies wallet ownership, and displays Arc Testnet state.

To find responsive role navigation logic visit [AppShell.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/components/AppShell.svelte).
