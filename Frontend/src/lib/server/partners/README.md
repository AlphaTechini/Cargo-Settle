# Partner Reads

This directory exposes workspace-scoped logistics-partner records for the forwarder portal. The projection uses membership, shipment participation, obligations, settlement accounts, early-payment requests, and settlements. Partner creation and assignment writes remain outside this read-only pass.

To find workspace partner aggregation logic visit [repository.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/server/partners/repository.ts).

To find partner response composition visit [service.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/server/partners/service.ts).

The workspace membership connection can be found in [schema.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/server/db/schema.ts).
