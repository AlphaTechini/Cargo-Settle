# On-Chain Shipment Setup

This endpoint returns the linked Arc wallets needed to register a database shipment and records a successful on-chain shipment creation after the forwarder wallet confirms it.

To find on-chain shipment setup handling visit [+server.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/routes/api/shipments/%5BshipmentId%5D/onchain/+server.ts).
