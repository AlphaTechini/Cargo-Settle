# On-Chain Funding Confirmation

This endpoint records a confirmed escrow funding transaction against a shipper-scoped funding intent and updates the related shipment funding fields.

To find funding confirmation handling visit [+server.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/routes/api/funding-intents/%5BfundingIntentId%5D/onchain/+server.ts).

The funding intent schema can be found in [schema.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/server/db/schema.ts).
