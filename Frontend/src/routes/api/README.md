# API Routes

The API route tree contains same-origin SvelteKit JSON endpoints. Authentication routes use database-backed sessions; health checks do not require database credentials.

To find authentication endpoints visit [auth](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/routes/api/auth). To find the runtime health endpoint visit [health/+server.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/routes/api/health/+server.ts).
