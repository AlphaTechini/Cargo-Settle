To find notification rendering and invitation acceptance visit [+page.svelte](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/routes/notifications/+page.svelte).

The notification persistence and invitation connection can be found in [service.ts](file:///C:/Hackathons/Cargo%20Settle/Frontend/src/lib/server/notifications/service.ts).
