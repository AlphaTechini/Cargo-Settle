# Project Decisions

- The initial backend stack is TypeScript, Fastify, Drizzle ORM, and PostgreSQL.
- The first schema slice is intentionally limited to users, shipments, shipment participants, and payment obligations.
- User roles are `shipper`, `freight_forwarder`, and `logistics_partner`.
- Logistics partners connect to freight forwarders through shipment participation, not a permanent direct forwarder field.
- Fastify validation uses TypeBox JSON Schema contracts that can be attached to route definitions.
- Drizzle migration SQL is generated by the CLI and is not manually maintained.
